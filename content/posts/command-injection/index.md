## 개념

프로그램이 외부 입력을 **셸 명령어의 일부로** 실행할 때, 입력에 명령어를 끼워 넣어
원래 의도에 없던 명령을 실행시키는 것.

## 왜 생기나

`system()`, `popen()` 처럼 문자열을 셸에 넘겨 실행하는 함수에,
사용자 입력을 검사 없이 이어 붙일 때 생긴다.

셸은 `;`, `|`, `&&`, `` ` ``, `$()` 같은 문자를 명령어 구분·연결로 해석한다.
입력에 이런 문자가 그대로 들어가면 명령이 쪼개지거나 추가된다.

## 예제

```c
char cmd[128];
snprintf(cmd, sizeof(cmd), "ping -c 1 %s", user_input);
system(cmd);        // 입력을 셸 명령에 그대로 붙임
```

정상 입력이면 `ping -c 1 8.8.8.8`이 실행된다.
그런데 입력으로 `8.8.8.8; id`를 넣으면 셸은 이렇게 본다.

```
ping -c 1 8.8.8.8 ; id
```

`;` 뒤의 `id`가 별도 명령으로 추가 실행된다.
`;/bin/sh` 같은 걸 붙이면 셸을 띄울 수도 있다.

## 영향

- 프로그램 권한으로 임의 명령 실행.
- 메모리 보호기법(NX, ASLR 등)과 무관하다. 메모리를 깨는 게 아니라 **문자열 처리**의 문제이기 때문.

## 정리

| 항목 | 내용 |
|---|---|
| 원인 | 사용자 입력을 셸 명령 문자열에 검사 없이 삽입 |
| 트리거 | `;` `\|` `&&` `` ` `` `$()` 등 셸 메타문자 |
| 핵심 | 데이터로 들어온 입력이 명령어로 해석됨 |
