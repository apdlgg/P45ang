## 개념

정수 자료형을 잘못 다뤄서 의도치 않은 값이 나오는 것.
대표적으로 **부호 오류**(signed/unsigned)와 **정수 오버플로우**가 있다.

## 1. 부호 오류 (signedness)

`signed`는 음수를 표현하고, `unsigned`는 0 이상만 표현한다.
같은 비트를 어느 쪽으로 해석하느냐에 따라 값이 완전히 달라진다.

```c
int size = -1;              // signed로는 -1
printf("%u\n", size);       // unsigned로 해석하면 4294967295
```

길이 검사는 `signed`로 하고 실제 사용은 `unsigned`로 하면 문제가 생긴다.

```c
int len = get_input();          // 사용자가 -1을 넣음
if (len > 100) return;          // -1 > 100 은 거짓 -> 검사 통과
memcpy(dst, src, len);          // len이 unsigned로 해석되어 매우 큰 복사
```

작은 값인 척 검사를 통과한 뒤, 실제로는 거대한 크기로 쓰인다.

## 2. 정수 오버플로우

자료형이 담을 수 있는 최대값을 넘으면 값이 돌아간다(wrap around).

```c
unsigned char c = 255;
c = c + 1;       // 256이 아니라 0으로 돌아감
```

크기 계산에 오버플로우가 끼면, 작아진 값으로 버퍼를 할당한 뒤 원래 크기로 쓰는 식의
어긋남이 생긴다.

## 영향

- 길이·크기 검사를 우회한다. "작은 값"으로 통과한 뒤 "큰 값"으로 동작.
- 그 결과 버퍼 오버플로우나 OOB 같은 2차 문제로 이어지는 경우가 많다.

## 정리

| 항목 | 내용 |
|---|---|
| 부호 오류 | signed/unsigned 해석 차이로 음수가 거대한 양수가 됨 |
| 정수 오버플로우 | 최대값을 넘으면 값이 wrap around |
| 핵심 | 검사할 때와 쓸 때의 자료형 해석이 다르면 검사가 무력화됨 |
